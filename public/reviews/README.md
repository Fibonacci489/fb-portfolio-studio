# Reviews Media Directory

Drop your review assets here:
- **Videos** (5-30 minute MP4/WebM files): public/reviews/videos/ (or use YouTube, Vimeo, Loom links in src/data/content.ts)
- **Images** (screenshots, WhatsApp feedback, client results): public/reviews/images/

Refer to them in src/data/content.ts under the REVIEWS array.
