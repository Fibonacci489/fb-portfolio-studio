2. VISUAL DESIGN SYSTEM

Create a luxurious, futuristic, professional aesthetic inspired by black diamonds, polished obsidian, precision-cut gemstones, metallic silver, and global technology networks.

Color palette

Primary background: #030507

Secondary background: #080C10

Card background: #0B1015

Primary text: #F5F7FA

Secondary text: #A8B2BE

Metallic silver: #C7CDD5

Highlight silver: #F2F4F7

Border: rgba(192, 204, 218, 0.22)

Background treatment

Use subtle faceted black-diamond textures.

Introduce low-contrast geometric reflections and obsidian-like surfaces.

Apply restrained metallic highlights and soft silver glows.

Use fine borders and carefully controlled shadows.

Add a subtle world map or connected-node graphic in the hero area.

Keep text and content readable against all backgrounds.

Do not use bright gold, excessive neon, colorful gradients, cartoonish icons, or distracting animations. The design should feel premium and sophisticated rather than flashy.

Typography

Use a clean modern font such as Inter, Manrope, or a similar professional sans-serif.

Use large, bold headings, readable body text, consistent spacing, and clear visual hierarchy. Use metallic serif typography only as a restrained accent where it complements the FB logo.
